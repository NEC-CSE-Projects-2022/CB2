Methodology

The proposed system introduces a hybrid deep learning–based Intrusion Detection System (IDS) designed to accurately identify cyber threats in modern network environments. The methodology integrates data preprocessing, feature optimization, and a CNN–BiLSTM hybrid model to effectively capture both spatial and temporal patterns present in network traffic.

1. Dataset Description

The experiments are conducted using the CICIDS2017 dataset, a widely recognized benchmark created by the Canadian Institute for Cybersecurity. This dataset simulates real-world network traffic and contains both benign and malicious activities collected over five consecutive days.

Attack categories included:

  • DoS and DDoS attacks (Hulk, GoldenEye, Slowloris, SlowHTTPTest)
  • Brute Force attacks (SSH and FTP)
  • Port Scanning
  • Botnet activity
  • Web-based attacks (SQL Injection, XSS, Command Injection)
  • Infiltration attacks

Each network flow is represented by more than 80 statistical and time-based features, extracted using the CICFlowMeter tool. These features include flow duration, packet statistics, inter-arrival times, header information, active/idle times, and flag-based metrics, making the dataset suitable for intrusion detection research.

2. Data Preprocessing

Raw network traffic data often contains noise and inconsistencies that can negatively impact model performance. To ensure reliable learning, the following preprocessing steps are applied:

  • Handling missing and infinite values: All records containing NaN, infinite, or undefined values are removed.
  • Dropping irrelevant attributes: Non-informative fields such as source IP address, destination IP address, and timestamps are eliminated.
  • Label encoding: Categorical attack labels are converted into numerical form for model compatibility.
  • Feature normalization: Numerical features are standardized using z-score normalization to maintain uniform scale and improve convergence during training.

3. Feature Selection Using PCA

To reduce dimensionality and eliminate redundant information, Principal Component Analysis (PCA) is applied to the preprocessed dataset. PCA transforms the original high-dimensional feature space into a smaller set of principal components while preserving most of the variance.

This process reduces the feature set from over 80 attributes to approximately 30 optimized components, significantly improving:

  • Computational efficiency
  • Training speed
  • Generalization capability
  • Resistance to overfitting

4. Data Reshaping

After feature optimization, the dataset is reshaped to meet the input requirements of the deep learning model. Since the CNN component expects three-dimensional input, the optimized feature vectors are converted from 2D to 3D format. This enables the convolutional layers to effectively scan feature patterns across the input space.

5. Hybrid CNN–BiLSTM Model Architecture

The core of the proposed system is a hybrid CNN–BiLSTM architecture designed to capture both spatial and temporal characteristics of network traffic.

Convolutional Neural Network (CNN)

  • Extracts local and spatial patterns from network flow features
  • Identifies short-term variations in packet behavior and traffic intensity
  • Includes pooling layers to reduce dimensionality
  • Uses dropout layers to prevent overfitting

Bidirectional Long Short-Term Memory (BiLSTM)

  • Processes sequential data in both forward and backward directions
  • Captures long-range temporal dependencies in network traffic
  • Enhances detection of attacks that evolve over time

The output from the BiLSTM layer is passed to a fully connected dense layer, which aggregates learned representations for classification.

6. Classification and Prediction

In the final stage, a Softmax activation function is applied to generate probability scores for each class. Based on these probabilities, the model classifies network traffic as either normal (benign) or malicious (attack).

This probabilistic approach ensures accurate, interpretable, and reliable intrusion detection suitable for real-time environments.

7. Overall Workflow

  • Raw network traffic collection
  • Data cleaning and normalization
  • Label encoding
  • PCA-based feature reduction
  • Data reshaping
  • CNN–BiLSTM hybrid learning
  • Final attack or normal traffic prediction

Summary

By combining PCA for feature optimization with a CNN–BiLSTM hybrid architecture, the proposed methodology achieves high detection accuracy while maintaining computational efficiency. This makes the system suitable for deployment in real-time cybersecurity applications, including industrial IoT, smart cities, and critical infrastructure networks.
